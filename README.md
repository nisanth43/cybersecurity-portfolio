# Nisanth S — Cybersecurity Analyst Portfolio

Responsive cyber operations portfolio highlighting blue-team defense, red-team testing, incident response, threat intelligence, and security automation.

- `index.html`: portfolio content
- `styles.css`: responsive navy/cyan theme
- `script.js`: mobile navigation, current year and contact form
- `assets/Nisanth-Resume.pdf`: resume download

Open `index.html` in a browser to preview. The contact form uses `mailto:` and opens the visitor's email app with a pre-filled message; it does not directly send or store submissions. For direct form submissions, connect a form service or backend.

Cloudflare Pages: sign in at https://dash.cloudflare.com/, open Workers & Pages, create a Pages project, and upload the site files with `index.html` at the root.
