# Nisanth S — Cybersecurity Portfolio

A responsive, single-page cybersecurity portfolio built with HTML, CSS, and vanilla JavaScript. The résumé PDF is bundled at `assets/Nisanth-Resume.pdf` and linked with a relative path, so the download works when the complete folder is deployed.

## Files
- `index.html` — page content and résumé links
- `styles.css` — responsive styling and animations
- `script.js` — mobile navigation and reveal effects
- `assets/Nisanth-Resume.pdf` — résumé PDF used by the download buttons

## Deploy to GitHub Pages / Cloudflare Pages or Workers Static Assets
Upload the contents of this folder to the root of the connected repository, preserving the `assets` folder. Commit and push. The deployment must publish this folder as the site root. Confirm the PDF is accessible at `/assets/Nisanth-Resume.pdf` after deployment.

If the site is served from a subdirectory, update both résumé links in `index.html` to the correct relative path.
